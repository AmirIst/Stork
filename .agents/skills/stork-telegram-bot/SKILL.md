# Навык: Архитектура и паттерны Telegram-бота Stork

Этот навык аккумулирует проверенные инженерные решения, архитектурные правила и сценарии устранения сбоев для Telegram-бота Stork (изучение немецкого языка).

---

## 1. Отказоустойчивый синтез речи (Text-to-Speech)

### Проблема облачных IP (Heroku / AWS)
Библиотека `edge-tts` подключается к WebSocket серверам Microsoft. В облачных средах дата-центры Microsoft часто блокируют или обрывают эти соединения с кодом `403 Forbidden` или `WSServerHandshakeError`. В результате пользователи видят ошибку `Audio synthesis failed`.

### Архитектурное решение: Двухуровневый TTS
1. **Первичный движок (Edge-TTS)**:
   - Высококачественные студийные нейронные голоса: `de-DE-KillianNeural` (мужской) и `de-DE-KatjaNeural` (женский).
   - Запуск строго с таймаутом (4 секунды через `asyncio.wait_for`), чтобы бот не зависал при сетевых сбоях.
2. **Резервный движок (Google Translate TTS)**:
   - Не требует API-ключей, работает по стандартному HTTP GET через `httpx.AsyncClient`.
   - Никогда не блокируется на облачных IP-адресах.
   - Поддерживает чистую немецкую речь (`tl=de`).
3. **Умная нарезка (Chunking)**:
   - Длина запроса к резервному API не должна превышать 180 символов.
   - Разбивка выполняется по знакам препинания (`.`, `!`, `?`, `;`).
   - Полученные MP3-байты конкатенируются в единый аудиопоток.
4. **Кэширование**:
   - Словарь `_AUDIO_CACHE` (до 500 записей) в памяти бота исключает повторные запросы для популярных слов.

### Безопасная отправка в Telegram
```python
voice_file = BufferedInputFile(audio_bytes, filename=f"{word}.mp3")
try:
    await callback.message.answer_voice(
        voice=voice_file,
        caption=caption,
        parse_mode="Markdown"
    )
except Exception:
    # Защита от сбоев разметки Markdown в примерах
    await callback.message.answer_voice(
        voice=voice_file,
        caption=clean_text,
        parse_mode=None
    )
mark_voice_sent(callback.from_user.id)
```

## 2. Интерактивная «Тренировка дня» (Daily Workout)

### 3-шаговый цикл удержания (Retention Loop)
1. **Шаг 1: Слова дня (5 слов)**:
   - Выборка по текущему уровню пользователя (`A1`, `A2`, `B1`).
   - Карточка слова с артиклем, переводом и примером предложения.
   - Кнопка озвучки `wo_voice:{word_id}`.
   - Корректная обработка множественного числа: если база уже содержит `die`, не дублировать артикль.
2. **Шаг 2: Блиц-артикли (5 существительных)**:
   - Быстрый выбор: `der`, `die`, `das`.
   - Мгновенный фидбек без задержек.
3. **Шаг 3: Вопрос дня от Аиста**:
   - Вопрос на разговорную тему (привязан к номеру дня в году).
   - Прием ответа текстом или голосом (автоматическое распознавание через `transcribe_voice`).
   - Оценка реплики через Gemini: похвала, исправление грамматики и идеальный вариант фразы.
   - Начисление +50 XP и инкремент ежедневного стрика.

### Защита от сброса FSM (Session Expiry)
При перезапуске сервера или истечении сессии состояние FSM очищается. Все шаги тренировки должны проверять наличие данных:
```python
data = await state.get_data()
words = data.get("words", [])
if not words:
    # Мягкий перезапуск шага вместо падения с IndexError
    await cb_start_step1(callback, state)
    return
```

## 3. Реферальная программа и генерация ссылок для шеринга

### Особенности Telegram Share (`t.me/share/url`)
- Telegram при отправке через `https://t.me/share/url?url=...&text=...` всегда ставит саму ссылку на **первую строку** сообщения.
- **Антипаттерн**: текст «Присоединяйся по ссылке:» или висячие двоеточия в конце текста. В чате это выглядит оборванным.
- **Правильный паттерн**: живой, вовлекающий текст от первого лица:
  - RU: *«Учу немецкий язык в умном боте Stork! 🇩🇪🪶 Тут есть интерактивные тренировки, разговорный клуб и подготовка к экзаменам. Залетай прокачивать язык вместе!»*
  - EN: *«I'm learning German with AI tutor Stork! 🇩🇪🪶 Interactive daily workouts, speaking practice, and exam prep. Come join me!»*

## 4. База данных и облачный запуск (Heroku + Turso)

1. **Работа с базой данных**:
   - Все методы выборки должны иметь безопасные fallback-значения.
   - Обязательно проверять наличие вспомогательных методов (например, `db.get_user(user_id)`).
2. **Тип процесса на Heroku (`Procfile`)**:
   - Запуск через `web: python bot.py`.
   - Переменная `PORT` передается Heroku динамически. Бот запускает легковесный веб-сервер aiohttp для приема вебхуков (Tribute / оплата) и параллельно крутит long-polling Telegram.
   - При смене `worker` на `web` в Heroku Dashboard (вкладка Resources) необходимо явно включить тумблер `web` dyno.
3. **Управление окнами интерфейса (`services/ui_helper.py`)**:
   - Редактирование сообщений на месте (`edit_text`) сохраняет чистоту чата.
   - Функция `mark_voice_sent(user_id: int)` синхронная и принимает один аргумент (`user_id`).
   - Если бот отправил аудиозапись ниже окна, следующее действие пересоздает окно внизу чата (`need_repost`).
